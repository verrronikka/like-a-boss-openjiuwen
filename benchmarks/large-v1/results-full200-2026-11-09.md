# Полный прогон 200 задач 9 ноября 2026

Через настоящий API NeuralDeep обработаны все 200 задач набора v1. Отдельная проверялка подтвердила **159 из 160 решаемых задач и 40 из 40 правильных отказов**. Получено **757 из 766 баллов (98,8%)** при расходе **96639 из 100000 взвешенных токенов**.

## Конфигурация и воспроизводимость

- Исходный коммит: `82d54ad`.
- Модель: `qwen3.8-27b-noreason` через openJiuwen; стандартный планировщик `density`, проверки решаемости включены. Это не полный сравнительный прогон `knapsack`.
- Параметры: `BUDGET=100000`, `--budget 100000 --task-budget 4000 --max-steps 12 --max-output 2048 --time-limit 3300`.
- Docker: 4 CPU, 16 GB RAM, файловая система образа только для чтения, временная папка до 2 GB. Агенту монтировались только чистые копии `tasks`.
- Время контейнера: 1657,4 секунды, около 27 минут 37 секунд. Код завершения — 0.
- SHA256 исходного набора: `29966a3e394c6af25cd7955b51cf5358925852d6b3de1d603a654de43bd76db8`.
- Эталоны, референсные программы и разметка решаемости агенту не передавались. Все 200 задач имеют фактический расход API; нет задач, попавших в отчёт только из-за недостатка бюджета.

Сохранились 160 ответов и 40 осознанных отказов; нет ложных пропусков, выдуманных ответов на нерешаемые задачи или незавершённых попыток. Статус `submitted` сам по себе не означал правильность: один из сохранённых ответов не прошёл независимую проверку.

## Расход

772 запроса: 611720 входных и 35467 выходных токенов. По формуле соревнования: `611720 / 10 + 35467 = 96639`. Остаток — 3361. Вызовы проверки решаемости и подтверждения отказов включены в расход: 201 предварительная проверка, 41 аудит отказа и 530 запросов основного цикла.

На нерешаемые задачи ушло 11096,3 токена, около 11,5% расхода. Отказы не принесли баллов. Максимальный расход одной задачи — 2447,8, ниже установленного лимита 4000. Остановок по бюджету, времени и ошибкам API не было.

## Единственная ошибка

`item_6af1c8547dccc01e`, семейство `math/travel`, награда 9:

```text
57 км/ч × 9 ч + 64 км/ч × 3 ч = 513 + 192 = 705 км
```

Модель сдала `729`. В траектории после подтверждения решаемости есть сразу `submit_answer`, без вычисления через Python. Эталон `705` корректен. Ошибочный ответ сохранён в материалах опыта; результат не исправлялся вручную и задача не перезапускалась ради повышения баллов.

В предыдущих коротких прогонах на 10000 токенов эта же задача была решена верно обоими планировщиками. Это пример изменчивости генерации. Следующая возможная доработка — обязательная инструментальная проверка числовых ответов; в этом опыте её ещё нет.

Это один диагностический опыт на синтетических шаблонах: 20 семейств с вариациями чисел и фактов, а не 200 независимых реальных проектов. После просмотра результатов набор нельзя считать новым закрытым тестом для последующих доработок. Для следующей независимой оценки нужны новые семейства.

Прогноз расхода и вероятность успеха пока не обучались, веса Qwen не менялись.
